# portfolio-website

Yazan Alatrach's personal portfolio site — a single-page React app with hero, projects, about, resume, and contact sections.

## Stack

React 19 + Vite 7 + Tailwind CSS 3. No backend, no router; contact form submits directly to Web3Forms.

## Getting started

```bash
npm install
npm run dev      # local dev server
npm run build    # production build
npm run lint     # eslint
```

## Where content lives

- All page content and sections: `src/App.jsx`
- Resume file served at `public/Resume.pdf`

Deployed as a static Vite build on Vercel.
